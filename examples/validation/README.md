# Validated benchmark examples

These files were generated by the release solver. The JSON records the three models, reference definitions and acceptance thresholds. The two CSV files contain measured errors and paired refinement changes. The PNG plots the same convergence data.

| Case | Inputs | Verification |
| --- | --- | --- |
| Generated slab | 0.20 m × 0.10 m × 0.02 m, equal wall temperatures of 300 K and generation of 24,000 W/m³ | Analytical parabolic profile, 10×5 through 80×40 cells |
| Insulated transient rectangle | Same geometry, no generation and an initial 2D cosine perturbation of 30 K about 300 K | Continuum and exact-in-time discrete references, fixed 20×10 grid, 10 through 640 steps at 140 s |
| Mixed energy audit | Fixed temperature, convection, insulation and prescribed flux on separate sides, with generation | Stepwise and integrated conservation from solved fields and boundary powers |

Run from the project root to regenerate the full PDF, figures and CSV data.

```bash
python -m heatlab.scientific_reporting --output validation-report
```

این داده‌ها خروجی حل‌گر نسخهٔ انتشارند. فایل JSON ورودی‌ها و معیارها را ثبت می‌کند و جدول‌های CSV خطا و تغییر بین ریزسازی‌های متوالی را نشان می‌دهند.
